# KRUNKED // FORGE DECK — Spec

## Launch URL resolution (`resolveLaunch`)
1. Override `launchUrl` wins.
2. Else `homepage` if a valid http(s) URL.
3. Else `has_pages` → `https://<user>.github.io/<repo>/` (the repo `<user>.github.io` → `https://<user>.github.io/`).
4. Else `null` → `kind = 'code'`; otherwise `kind = 'live'`.

Repos excluded: forks, archived, override `hidden` (the deck repo itself is hidden by default).

## Classification
Category = override → keyword heuristic over name/topics/description (Game, Hardware/Sky, Audio/Vinyl, Automation) → `App` (live) | `Utility` (code, <200 KB) | `Engine` (code).

## Freshness (`lastActivityAt = max(pushed_at, latest PushEvent)`)
| Age | Tier | Colour | Badge | Beacon |
|---|---|---|---|---|
| <24 h | fresh | Emerald `#10B981` | `SHIPPED 12m AGO` | pulse |
| <72 h | active | Amber | `UPDATED 2d AGO` | pulse |
| <7 d | active | Amber | `UPDATED 5d AGO` | — |
| else | idle | neutral | `IDLE 5w` | — |

Live PWAs get an Electric Cyan `PWA` chip (detected by probing the launch page for `link[rel=manifest]`).

## Procedural cover system
`seed = cyrb53(name|language|topics)` → `mulberry32` PRNG. Style: override → category (Game→synthwave, Hardware/Sky→orbital, Audio/Vinyl→groove, Automation→prism, else topo) → `seed % 5`.
Hue: override accent → probed `theme-color` → `seed % 360`; hues in 255–295° (indigo/purple) are remapped ±40°. Palette in OKLCH (`key L.74 C.15`, `deep L.28 C.08`, `counter h+150`).
Renderers draw on `<canvas>` with DPR scaling, finish with vignette + fade to `#0D1015`. Results memoised in `coverCache`; spotlight lead tile animates (rAF, in-view + visible + motion allowed only). Image precedence: override screenshot > probed `og:image` > procedural.

## Visual tokens
Surfaces `#07080A / #0D1015 / #131820 / #1A202B`, hairline `rgba(255,255,255,.07)` (hover: pointer-tracked radial specular ring via `--mx/--my`), film grain at 3.5 % opacity.
Fonts: Geist Variable (display/UI), Instrument Serif italic (editorial accent), JetBrains Mono (telemetry, tabular numerals).
Motion: spring `{stiffness:380, damping:32}`, FLIP via `layout`/`layoutId`, `MotionConfig reducedMotion="user"`, CSS keyframes disabled under `prefers-reduced-motion`.

## Layout
TopBar (wordmark, live clock, sync pill, ⌘K, settings, force sync) → HeroBand (headline, stats, 90-day heat strip) → "Fresh off the forge" (SpotlightDeck 8 col + ForgeStream 4 col; mobile = snap carousel + ship-log sheet) → FlagshipDock (reorderable pins) → FilterBar (pills, view switcher, sort) → collection view (Showcase Bento | Telemetry Grid | Ship Matrix) → StatusBar.

## Persistence (`krunked-cookie-vault-v1`)
`{v:1, pins[], prefs{view,sort,filter}, seen{repo:sha}, updatedAt}` → localStorage full copy + cookie mirror (compact, `seen` dropped if >3500 B). Read picks the valid copy with newest `updatedAt` and heals the other. Debounced 250 ms.

## PWA
`manifest.webmanifest` (standalone, `#07080A`, 192/512/maskable PNG icons generated by `scripts/generate-icons.mjs`), network-first navigation SW with precached hashed assets, registered only in production, scope-safe (see ARCHITECTURE §5).

No `TODO/FIXME`. 5. Live hydration against `api.github.com/users/krunked-fpv/repos` works. 6. Desktop + mobile screenshots show no breakage.
